## Objetivo de la práctica

Aplicación web de chat con Inteligencia Artificial orientada a temas relacionados con las Tecnologías de la Información y Comunicaciones (TIC).

El proyecto cuenta con una interfaz web responsive, integración con una API desplegada en Vercel y conexión con un modelo de OpenAI para generar respuestas dinámicas.

---

## Descripción

Este proyecto consiste en una aplicación web que permite al usuario interactuar con un asistente de Inteligencia Artificial.

El asistente está configurado para responder en español de manera clara, breve y didáctica, especialmente sobre temas relacionados con las TIC.

Además, el sistema conserva el historial de conversación durante la sesión para que el modelo pueda mantener el contexto entre diferentes mensajes.

Por ejemplo:

```text
Usuario:
¿Qué son las APIs?

IA:
Una API es una interfaz que permite que dos sistemas se comuniquen...

Usuario:
¿En qué contexto las podría aplicar?

IA:
Las APIs pueden utilizarse en aplicaciones web, móviles, pagos,
mapas, inteligencia artificial, IoT, entre otros contextos.
```
